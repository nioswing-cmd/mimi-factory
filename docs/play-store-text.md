## ⚠️ 정책 주의사항 (심사 전에 꼭 확인)

1. **「도파민 실험실」이 가장 위험합니다.**
   `ADHD 테스트` `번아웃` `IQ` `다중지능 검사` 같은 항목이 있어, 구글이
   *건강 콘텐츠 / 오해를 부르는 주장* 정책으로 볼 여지가 있습니다.
   - 앱 이름·간단한 설명에 `진단` `검사` `치료` `측정` 단어를 쓰지 마세요.
   - 위 자세한 설명에 넣어 둔 「⚠️ 꼭 읽어주세요」 면책 문구를 **지우지 마세요.**
   - 앱 안 화면(test.html 및 각 테스트 첫 화면)에도 같은 취지의 한 줄이 보이는 것이 안전합니다.
     현재 `ADHD 성향 테스트`는 앱 안에서 이미 "성향"으로 표기되어 있으나,
     `apps.json`의 제목은 아직 `ADHD 테스트`입니다 — **`ADHD 성향 테스트`로 맞추는 것을 권합니다.**

2. **스크린샷에 결과 화면을 넣을 때** 점수·등급이 의학적 판정처럼 보이지 않게 하세요.

3. **콘텐츠 등급 설문**에서 「둘의 피크닉」은 연애·관계 주제가 있으므로
   해당 문항에 정직하게 답하세요. (숨기면 나중에 앱이 내려갑니다)

4. **저작권** — 「밤의 서재」는 실제 도서 제목과 저자를 사용합니다.
   퀴즈는 저작물의 내용을 요약·문제화한 2차적 성격이므로,
   본문을 그대로 인용하는 문항이 있는지 확인하시고 표지 이미지는 자체 제작본만 사용하세요.

5. **PWA를 앱으로 포장할 때** start_url이 `?app=1`이어야 다른 관으로 가는 메뉴가 숨겨집니다.
   (매니페스트에는 이미 반영되어 있습니다)

6. **현재 "전 서가 풀버전 무료 오픈 중" 배너가 떠 있습니다.**
   나중에 유료로 바꾸시면 스토어 설명의 "앱 내 결제 없음" 문구와
   데이터 보안 양식을 **반드시 같이 고쳐야** 합니다.
