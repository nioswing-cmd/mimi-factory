# 상황극 중독자 생활편 — 제작 자료

🏠 같이 살면 반드시 터지는 것들 — 에어컨 온도부터 물건 버리기까지

둘이서 폰 하나를 놓고 **정반대 입장**을 맡아 즉흥 연기로 붙는 게임.
핵심은 하나다 — **두 역할의 목표가 정면으로 충돌해야 한다.** 그래야 웃긴다.

## 디자인 (다른 편과 확실히 달라 보이게)

**해질녘 거실.** 따뜻한 흙빛(#1c1614)에 크림(#f4e9dc)과 테라코타(#e0794f) 강조. 종이 질감처럼 담백하게. 카드는 각이 살짝 살아 있게. 생활감 있는 아이콘(주전자·양말·리모컨)을 곳곳에 작게 쓴다.

이 앱은 「상황극 중독자」 시리즈 중 **🏠 생활편**이다. 시리즈의 다른 편
(연애·생활·회사·가족·황당)과 **색과 분위기가 한눈에 구분되어야 한다.**

## 수위 3단계 — 상황마다 LV가 붙어 있다

- **LV.1 몸풀기** — 웃으면서 할 수 있는 가벼운 실랑이
- **LV.2 슬슬** — 은근히 신경 긁히는 갈등
- **LV.3 정면충돌** — 갈등이 진짜 센 것. 목소리 커지는 자리

## 맛 고르기 (진실게임과 같은 방식으로 만들 것)

시작 화면에 버튼 세 개를 나란히 둔다. **「순하다가 매운맛」이 기본 선택**이다.

- 🥛 **순한맛** — 웃으면서 할 수 있는 · LV.1~2 만 나온다
- 🌶️🌶️ **매운맛** — 바로 본론부터 · LV.2~3 만 나온다
- 🥛→🌶️ **순하다가 매운맛** — 점점 세지게 · 전체에서 **LV.1 → LV.2 → LV.3 순서로** 나온다 (기본)

## 화면 흐름 (이대로 만들 것)

1. **시작** — 두 사람 이름 입력(🅰 / 🅱). 맛 고르기. 규칙 안내.
2. **뽑기** — 큰 카드를 탭하면 상황이 뒤집히며 공개된다.
3. **연기** — 한 화면에 이렇게 보여준다.
   - 상황 제목과 배경 한 줄
   - 🅰 역할 / 목표, 🅱 역할 / 목표 (두 칸 나란히, 서로 다른 색)
   - **첫 대사** — 먼저 읽고 시작하라고 안내한다
   - **90초 타이머** (시작/일시정지). 남은 시간이 20초 아래면 색이 바뀐다.
4. **반전** — 타이머가 30초 지날 때 「반전 카드」 버튼이 나타난다. 누르면 상황이 뒤집힌다. 안 눌러도 된다.
5. **판정** — 「누가 먼저 무너졌나?」 🅰 / 🅱 / 무승부 세 버튼. 각 상황의 패배 조건을 함께 보여준다.
6. **점수판** — 판이 끝날 때마다 점수 누적. 5판을 채우면 결과 화면으로 간다.
7. **결과** — 승패 요약 + 등급 + 둘의 케미 한 줄 + 다시하기 / 공유.

## 재미 장치 (반드시 넣을 것)

- **역할 바꾸기** — 같은 상황을 역할만 맞바꿔 한 판 더. 이게 제일 웃긴다.
- **명대사 저장** — 연기 중 웃겼던 대사를 한 줄 적어두는 칸. 결과 화면에서 모아 보여준다.
- **연속 승리 콤보** — 2연승 「기세」, 3연승 「독주」, 4연승 이상 「폭군」 표시.
- **순한 벌칙 룰렛** — 진 사람이 뽑는다. 애교 5초 / 상대 성대모사 / 셀카 한 장 / 칭찬 세 개 /
  다음 판 상대가 역할 지정 / 통과권 1회 쓰기.
- **통과권** — 각자 게임당 1번. 하기 싫은 상황을 다시 뽑을 수 있다.

## 케미 한 줄 (승패 차이로 고른다)

- 5:0 또는 0:5 — "한 명이 너무 잘한다. 다음엔 핸디캡을 주자."
- 4:1 / 1:4 — "실력 차가 보인다. 역할 바꾸기부터 하고 다시."
- 3:2 / 2:3 — "이게 제일 재밌는 점수다. 둘 다 안 봐줬다."
- 무승부가 많으면 — "둘 다 안 무너진다. 매운맛으로 올릴 때가 됐다."

## 규칙 안내문 (시작 화면에 넣을 것)

- 폰 하나를 가운데 두고 나란히 앉는다.
- 첫 대사는 카드에 적힌 사람이 먼저 읽는다. 그다음부터는 즉흥이다.
- **역할을 배신하지 마라.** 내 목표를 끝까지 밀어야 상대가 무너진다.
- 진짜로 화내지 않는다. 이건 연기다.
- 판정은 둘이 합의해서 누른다. 애매하면 무승부.
